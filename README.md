# shoman4eg/tap

Homebrew tap for shoman4eg's tools.

```sh
brew tap shoman4eg/tap
brew trust shoman4eg/tap
brew install <formula>
```

`brew trust` explicitly allows Homebrew to run formulas from this third-party tap.

## Formulas

| Formula | Description |
|---|---|
| [`dowel-craft`](https://github.com/shoman4eg/dowelcraft) | Cabinet furniture design: parts, sheet cutting, drilling, drawings (early alpha). Installs `dowel-craft-gui`, `dowel-craft` and `dowel-craft-mcp`. macOS (Apple Silicon, Intel) and Linux x86_64. |
